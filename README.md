# 이 모듈은 더 이상 개발되지 않습니다

이 모듈(`dw-instant-npc`)의 기능은 [dw-automation](https://github.com/Nomal-1/dw-automation) 모듈에 통합되었습니다.

`dw-automation`은 NPC 이름·본능·재주 무작위 생성 기능을 그대로 포함하면서, 몬스터 스탯 자동 생성, 공격 성공 시 데미지 자동 굴림 등 추가 자동화 기능을 모듈 설정에서 켜고 끌 수 있도록 제공합니다.

새로 시작하는 캠페인이라면 `dw-instant-npc` 대신 `dw-automation`을 설치하는 것을 권장합니다.

## 왜 업데이트가 끊겼나요?

- **기능이 `dw-automation`에 통합되었습니다.** 이 모듈이 하던 NPC 이름·본능·재주 무작위 생성은 `dw-automation`이 같은 방식으로 제공하고 계속 관리합니다. 같은 일을 하는 모듈을 둘 다 유지하면 수정 사항이 갈라지고, 두 모듈이 한 NPC 시트에 같은 버튼을 중복해서 붙이는 문제도 생깁니다.
- **Foundry 14를 지원하지 않습니다.** 마지막 릴리즈(v1.1.1)는 Foundry 12 전용이며, `module.json`의 호환 최대 버전(`maximum`)을 12로 둔 채 개발이 종료되었습니다. Foundry 13 이상에서는 설치·활성화되지 않을 수 있습니다. 14로 올라가려면 `dw-automation`으로 옮겨 주세요.
- 이 저장소는 보관(아카이브) 상태라 더 이상 수정되거나 릴리즈되지 않습니다. 이미 설치한 모듈은 Foundry 12 환경에서 계속 쓸 수 있습니다.
